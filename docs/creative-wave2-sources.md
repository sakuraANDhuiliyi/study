# 创意广场第二批：20 件作品来源清单

本批新增 20 件不同主题的创意 UI，对应 20 个不同 GitHub 仓库，许可为 19 件 MIT、1 件 ISC。每件作品记录完整 40 位固定提交，附源码路径与许可全文；它们是可以交互、预览和创建为学习项目的界面作品，不能把上游整站、引擎或后端能力当作已经迁入。

以下范围直接对应当前模板中的 `source.scope` 与 `source.changes`。公式或小段流程的适配、以及概念借鉴后的独立实现分别标清。完整著作权与许可在项目 `NOTICE.txt` 中，创建项目和下载时保留。
