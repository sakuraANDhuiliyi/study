# 学科专业学习中心与个人学习空间

专业学习中心把专业目录、可运行的课程工具、原创知识练习和结构化学习工作稿连在一起。学生可以读原理、修改参数、执行练习、查看过程，再把结果和自己的笔记保存在当前学习空间。个人注册后即可使用；组织学生保留原有课程、班级、作业和考试入口。

当前内置 **15 个学科分类、76 个专业模板、54 个学习模块**：32 个计算工具、18 个学习工作台、2 组知识练习、1 个 SQL 实验室及 1 个算法工作台入口。数量来自 [专业目录源码](../apps/api/src/academics/academics.catalog.ts) 和 [模块注册表](../apps/api/src/academics/academics.modules.ts)。这是一套可扩展的起步学习目录，包含交叉学科和通识分类，不是教育主管部门公布的完整专业目录，也不表示每个专业已经覆盖全部课程。多个专业可以推荐同一个基础模块。

## 学生使用流程

### 独立注册与定制

1. 在登录页切换“个人注册”，填写姓名或昵称、账号和密码。密码为 12–128 字符，注册成功后自动登录；个人账号固定为学生身份。
2. 在“我的学习空间”或“专业学习中心”打开“定制学习模块”。可以先选专业，也可以不选专业直接探索模块。
3. “加入该专业推荐模块”会把推荐内容加入现有选择。专业推荐是学习起点，不会限制访问其他公开模块；个人和组织学生都能扩展自己的模块选择。
4. 保存后，专业和模块偏好进入 PostgreSQL。首页统计和最近记录来自当前账号、当前空间的实际学习记录。

个人账号提供学习日历、个人学习笔记、专业学习中心、算法练习和 AI 错题复盘入口。课程、班级、组织作业、组织考试以及组织管理入口不出现在个人菜单中，直接打开组织教学路径也会显示权限说明。AI 服务仍取决于部署配置。

实现上，个人账号使用独立的私人数据空间，其 `accountMode` 为 `PERSONAL`；这不是加入一所教学机构。机构账号为 `ORGANIZATION`。两种模式共用登录与会话体系，并按空间隔离学习记录和偏好。

### 完成一次练习

模块工作台展示学习目标、概念、操作步骤、字段帮助和可载入的示例。数值、选择、文本、JSON、矩阵及勾选字段使用对应输入控件；载入示例会先确认是否替换当前输入。

- **计算工具**：提交到后端确定性计算引擎，返回指标、过程说明、表格以及适用时的采样图。每次成功执行保存一条新记录；参数错误会显示真实诊断，不生成成功结果。
- **知识练习**：页面要求先完成所有选择，提交后展示逐题参考选择与解释。题目详情不下发正确答案；提交结果按内置答案核对。
- **学习工作台**：保存学生自己的结构化文本，检查必填字段、类型、长度和文本结构；部分工作台还执行面积、时间、预算或术语出现情况的核对。
- **SQL 实验室**：执行受限的真实 SELECT 查询，并与固定教学任务的预期结果比较。
- **算法入口**：跳转到现有算法题库，使用它独立的代码草稿、运行、提交、题解与 AI 分析流程。

“结果与笔记”中可以修改记录标题、补充学习笔记，并把状态设为“继续研究”或“已完成”。“已完成”是学习记录状态，不等于全部答对、代码通过或专业能力达标。修改实验参数后再次运行会创建新记录，便于比较不同尝试；记录历史可恢复输入继续练习。

JSON／矩阵字段可输入如 `[100,200,300]`、`[[2,1],[1,3]]` 的文本。前端会把服务端对象形式的示例转成可编辑 JSON，服务端再按模块解析和校验。二维矩阵必须为规则数值矩阵；各工具还会检查维数、数值范围、单位和任务约束，错误不会被静默替换为默认值。

### 笔记与保存冲突

“自由学习笔记”支持主题、正文、标签与下一步行动，不依赖课程。个人侧栏“我的笔记”显示个人学习记录，也可以从“学习记录与笔记”按模块筛选。记录详情允许编辑标题、补充笔记与完成状态；需要修改原始工作稿或计算输入时，从对应模块历史恢复输入并保存新记录。

未提交的工作台输入和未保存的记录笔记会按账号、空间及模块／记录保存本机草稿。成功保存的记录则存储在服务器；清理浏览器存储后仍可从记录列表读取。浏览器存储不可用时，页面会提示及时保存。

偏好、记录笔记和目录修改都使用 `revision` 乐观锁。另一个窗口已经保存时返回 `409`，当前输入保留，页面显示冲突及最新内容，避免无提示覆盖。笔记按纯文本显示，`<vector>` 等代码符号不会被当作 HTML 执行。

## 组织加入、专业分配与数据边界

### 申请加入与审批

1. 机构管理员在“专业与成员申请”→“邀请码与加入审批”开启加入申请，获取邀请码。关闭加入开关会停止新的申请；更换邀请码会使旧码失效，已有申请仍保留。
2. 个人学生在“加入学习组织”填写邀请码和最多 500 字符的说明，提交后等待审核。邀请码只用于定位可申请的机构，不会自动授予组织成员身份。等待中的申请可以由本人撤回。
3. 管理员核对申请者并指定专业后批准，也可以驳回。批准会更新学生所属机构、账号模式和专业，并撤销其全部会话，学生需要重新登录。
4. 重新登录后显示组织教学菜单。课程、班级等具体资源仍取决于组织分配，不会因获得邀请码而自动加入全部课程。

管理员也可以在“用户管理”创建学生、编辑已有学生或通过 CSV 导入时填写 `majorId`。用户列表支持专业过滤和专业显示；CSV 不填写专业时留空即可。可分配范围为有效的公共专业模板及当前机构的专业，其他机构的专业不可使用。

组织学生的专业由管理员设置，学生的专业选择控件只读。学生仍可以自由定制学习模块，不能通过个人资料或偏好接口绕过专业分配。

### 返回个人空间

由个人账号加入机构、且当前仍为单一学生身份的成员，可以在“我的组织”选择“返回个人学习空间”。操作会撤销全部会话，停用该学生在原机构的班级与课程成员关系，并要求重新登录。管理员创建的普通组织账号没有原个人空间，不提供此返回能力。

个人空间原来的记录、笔记、模块偏好均保留；返回时恢复原个人专业，如果该公共专业已不可用则清空专业选择。组织空间产生的数据继续留在组织空间，不会自动复制到个人空间；历史教学记录不会因为退出而改写。以后再申请加入机构仍需管理员审批，原课程关系不会自动恢复。

学习记录始终按 **当前空间 + 本人** 查询。机构管理员管理目录和专业分配，并不因此获得读取学生专业学习私人笔记的接口。全局模板及机构目录可以被授权成员选择，个人笔记和输入不会成为公共教学内容。

## 管理员维护目录

“专业与成员申请”要求当前角色为 `ADMIN` 或 `SUPER_ADMIN`，并同时具有 `org.manage` 和 `users.manage`。界面入口、页面路由及服务端均使用这两项权限；仅拥有其中一项不会开放目录管理和加入审批。

- 公共学科与专业模板的 `organizationId` 为 `null`，后台只读。超级管理员也通过同一规则使用模板，不能从本机构页面直接改写全局模板。
- 管理员可复制模板为本机构条目，修改名称、说明、所属学科和推荐模块；也可以新建学科与专业。专业至少关联 1 个现有模块。
- 机构条目使用版本号编辑，归档通过 `active=false` 完成。归档后不再用于新的选择，历史引用和记录保留；已有专业关联可以继续显示归档标记。
- 归档一个学科前，须先停用它下面仍有效的专业。同机构不允许重复名称；当前机构最多创建 200 个学科、500 个专业。
- 自定义专业只是组织已有学习模块。增加新的计算器、问题集或工作台内容需要代码实现和相应验证，不会因新建一个专业自动生成未实现功能。

### 群体遗传课堂实验

“群体等位基因频率与模型期望”保留原双亲 Punnett 棋盘，提供独立的群体观察实验。输入 AA、Aa、aa 三种基因型计数，每项是 0–1,000,000 的整数，合计必须大于零；不接受缺失、字符串、小数、非有限值或额外字段。

先由计数得到 `N`、`A=2AA+Aa`、`a=2aa+Aa`，再计算 `p=A/(2N)` 和 `q=a/(2N)`。理想独立随机结合的三种期望频率为 `p²`、`2pq`、`q²`，各乘以 `N` 得到期望数量；期望数量可以是小数。[模型原理](https://openstax.org/books/biology-2e/pages/19-1-population-evolution)及[等位基因频率教材](https://bio.libretexts.org/Bookshelves/Genetics/Population_and_Quantitative_Genetics_%28Coop%29/02%3A_Allele_and_Genotype_Frequencies)用于核对事实，模块说明和课堂示例由本项目独立编写。

结果按 AA、Aa、aa 固定三行展示观察与期望数量、频率以及“观察减期望”差值。分组柱状图的横轴是基因型类别，纵轴是个体数，每类并列显示观察计数和模型期望计数；零值和小数保留，完整表格可作为图的文本替代。旧的数值折线图和无图记录继续使用原格式。

六个示例包括比例吻合、两类纯合个体、单个杂合个体、两个单等位基因端点和稀少等位基因。差值按未舍入数据计算，最后按有效数字展示，展示数字再次求和或相减可能有微小舍入差。差值是否为零不构成群体平衡、统计显著或掌握程度结论；“已完成”沿用完成一次实验的记录含义。

```http
Content-Type: application/json
x-csrf-token: 登录返回的当前令牌

{"values":{"countAA":0,"countAa":1,"countaa":0}}
```

该示例得到 `p=q=0.5`，模型期望数量依次为 `0.25`、`0.5`、`0.25`。合法结果保存完整参数、表格和分类图数据，可编辑个人笔记并导出；错误输入不产生记录。目标仍按实验记录计次，旧记录使用原持久化快照。

### 分层与汇总比例实验

“分层与汇总比例：辛普森反转”输入两个分层中方案 A、B 的达成数与总数，共八项整数。总数为 1–1,000,000，达成数为 0–对应总数；缺失、字符串、小数、非有限值、额外字段或达成数大于总数均拒绝，错误不创建学习记录。

默认原创样本为第一层 A=9/10、B=80/100，第二层 A=20/100、B=1/10。A 在两层都高 10 个百分点，但原始汇总 A=29/110、B=81/110，方向反转。原始汇总分别使用各方案自己的分层权重，不能直接平均两个百分数。

共同权重明确使用合并人数 `w_i=(n_Ai+n_Bi)/(N_A+N_B)`，两方案都计算 `Σw_i·r_i`。默认权重各半，结果 A=55%、B=45%；非等权示例把第一层 B 改为 160/200，权重变为 21/32、11/32，结果 A=65.9375%、B=55.9375%。共同权重结果是计算指标，不是新增观察人数。

三个表分别保留分层原始人数及自身权重、共同权重及贡献、四种口径的比例和方向。分类柱状图比较“分层1、分层2、原始汇总、共同权重”，纵轴为百分比；后两项是汇总口径。差值单位为百分点。六个示例包括严格反转、交换方案、非等权、相同样本构成、分层持平与分层混向。

比例、比较方向、权重贡献和差值采用 BigInt 有理数精确运算，最后才按约 11 位有效数字展示。显示比例相同仍可能有极小非零差值，方向以精确运算为准。只有两层严格同向、原始汇总严格反向才判为“严格反转”；另分为分层持平、分层混向、汇总持平及方向一致。这里比较给定计数的算术关系，不推断因果、显著性或方案优劣。“已完成”表示完成一次实验。

## SQL 实验室的执行方式

SQL 使用本地依赖 `sql.js` 的 SQLite WASM，在后端独立 Worker 线程中执行，每次重新创建固定的 `students`、`courses`、`enrollments` 教学表。它不连接 LMS 的 PostgreSQL，不接收数据库连接串，不读取用户指定文件，也不会修改真实学生或课程数据。Worker 使用空环境变量并在完成或超时后终止；这是线程与教学数据隔离，不是独立操作系统容器。

支持单条 `SELECT`、筛选、分组、排序及最多两次 `INNER`／`LEFT JOIN`；函数白名单为 `COUNT`、`AVG`、`SUM`、`MIN`、`MAX`、`ROUND`、`ABS`、`LOWER`、`UPPER`、`LENGTH`。完整语法解析后才生成执行计划，字符串常量参数化，并启用 SQLite `query_only`。写语句、外部表、任意函数、子查询、递归查询及注释不在当前教学语法范围内。

固定任务包括“高分学生”“课程平均分”和“Alice 的选课”。结果核对列名、行数、顺序和单元格，数值比较容差为 `1e-6`，截断结果不会判为任务匹配。页面同时列出实际查询表、预期表与任务说明；符合固定数据的输出不证明 SQL 对所有可能数据都正确。

资源边界包括：查询最多 4,000 字符／12,000 UTF-8 字节、最多 600 个 token、限制表达式深度与数量、每进程最多 4 个在途 Worker、执行超过 2 秒终止、最多 100 行和约 58,000 字节的输出。Worker 配置了 Node 堆与栈限制，但这些不是 WASM 内存的完整硬上限；受限语法、小规模固定数据和输出上限共同约束执行范围。忙碌、语法错误、环境失败或超时返回真实错误，学生输入仍可修改后重试。

| `PATCH /admin/join-settings`             | `{joinEnabled}`；切换是否接受新申请                                          |
| `POST /admin/join-settings/rotate-code`  | 空对象 `{}`；重新生成邀请码                                                  |
| `GET /admin/join-requests`               | `status,page,pageSize`；返回带申请者信息的分页列表                           |
| `PATCH /admin/join-requests/:id`         | `{status,majorId?}`；状态为 `APPROVED` 或 `REJECTED`，处理待审申请           |

申请状态为 `PENDING`、`APPROVED`、`REJECTED`、`CANCELLED`。已处理申请不会被重复批准；批准与退出均重新验证账号和组织状态、撤销现有会话，并写入审计记录。

个人账号可以按原账号安全流程预留并使用自己的恢复码，无需机构管理员许可；机构账号的恢复许可规则继续生效。登录与公开注册均有服务端频率限制。这里不提供管理员直接替已有用户改密码的接口。

### 目录管理接口

| 方法与路径                            | 输入与输出                                                    |
| ------------------------------------- | ------------------------------------------------------------- |
| `GET /academics/admin/subjects`       | `{items}`；公共和当前机构学科，包含归档条目                   |
| `POST /academics/admin/subjects`      | `{name,description?}`；创建机构学科                           |
| `PATCH /academics/admin/subjects/:id` | `{revision,name?,description?,active?}`                       |
| `GET /academics/admin/majors`         | `{items}`；公共和当前机构专业，包含归档条目                   |
| `POST /academics/admin/majors`        | `{name,description?,subjectId,moduleIds}`；创建机构专业       |
| `PATCH /academics/admin/majors/:id`   | `{revision,name?,description?,subjectId?,moduleIds?,active?}` |
| `GET /admin/users?majorId=…`          | 按专业筛选机构用户；用户创建、编辑及导入条目支持 `majorId`    |

学科公共字段为 `id,name,description,organizationId,active,revision`；专业还包含 `subjectId,moduleIds`。复制通过读取模板后提交新建接口完成，没有直接修改公共模板或删除历史引用的接口。版本过期返回 `409`，范围与权限错误返回 `403` 或不可见资源的 `404`。
