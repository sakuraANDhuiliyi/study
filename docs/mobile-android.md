# 知学 Android 客户端

## 原生算法学习与复习（0.12.0 / versionCode 12）

首页“算法学习”进入原生题库，可按题号、标题、知识点、难度、正式答题状态、收藏和复习状态筛选。题目与独立题解页包含样例、推导、边界及四语言只读参考代码，不使用网页嵌套代替迁移。

收藏、待复习/已掌握与私人笔记复用网站同一条学习记录，保存前确认并校验 revision。跨端冲突保留输入，加载服务器版本需明确舍弃；保存结果不明时冻结写入，通过只读核对确认是否已提交，避免重复写入。当前权限失效后隐藏题目和个人记录。

本轮同时修正 Android 输入焦点恢复：进入后台先收起键盘并移除输入焦点；返回键在输入框仍有焦点时先退出输入，避免切回考试后误触发离开确认。考试计时与后台尽力保存继续沿用原规则。

本轮无需新增数据库迁移，但服务器必须更新新增手机接口与锁定依赖。代码编辑、代码草稿、运行/提交判题、AI解析、训练计划和算法论坛尚未原生迁移，仍使用网站。完整范围见[迁移清单](mobile-migration.md)，验证结果见[本轮记录](verification/mobile-algorithm-learning-20261024.json)。

本项目新增 `apps/mobile`，使用 React Native / Expo 56、原生 WebRTC 和 Android 安全存储。它是学习平台的客户端，与 `services/android-agent` 中“帮助学生生成 APK”的编程工具分别部署；无需运行 Android Agent 才能登录或连麦。手机与网页共用现有后端、账号、权限、课程和数据库。

本轮结果见[完整验收记录](verification/mobile-android-20261017.json)，以及[原生首页](screenshots/mobile-android-home.png)、[双向连麦](screenshots/mobile-android-live.png)截图。截图使用隔离测试账号和模拟摄像头。

## 学习任务中心（2026-10-18）

底部“计划”和首页“学习计划”进入独立原生页面，不依赖 WebView。学生可查看今日、未来七天、逾期行动，按来源与当前授权课程筛选、搜索课程并分页；月度日程展示课程作业、考试和本人计划，包括已完成、已豁免和取消的日程。教师通过月度日程查看本人授权范围。

个人计划支持新增、读取最新版本、编辑、完成、恢复、确认删除以及未保存编辑的放弃确认。所有时间均按北京时间解释和展示，不受设备时区影响。并发更新沿用网站的 revision；冲突保留当前编辑，必须确认重新加载最新版本后才能继续保存。网络错误不自动重试创建，提示先刷新确认结果。计划只属于本人，课程任务继续由实时选课、发布状态、受众、延期与豁免规则限制。

本轮仅增加精确的 planner 原生路由许可，不开放管理、文件或考试写接口；无需新增数据库迁移。现有服务器仍需更新镜像后才能在新版 App 使用计划。学生作业目标现已进入原生页面；0.4.0 起学生考试作答已进入原生页面，教师相关入口仍通过网页独立登录，不把手机 token 放入链接。未完成部分见迁移清单。

完整迁移范围与未完成项见[迁移清单](mobile-migration.md)。本轮结果见[验收记录](verification/mobile-planner-20261018.json)与[任务中心截图](screenshots/mobile-android-planner.png)。

## 原生作业与成绩反馈（0.2.0 / versionCode 2）

首页“我的作业”、课程“查看课程作业”、学习行动与月度日程中的学生作业目标均进入原生页面。支持授权范围内的列表、搜索、分页、单选、多选、判断、填空、简答和综合题，查看个人延期、豁免与重交次数，保存草稿、明确确认正式提交、查看历史版本、复制历史答案重新作答。教师出题、批改与发布仍在网站，0.4.0 起学生考试已原生迁移。

网页与手机保存草稿使用相同 revision；正式提交同时核对草稿 revision 和已有提交版本。冲突保留当前输入，需确认加载网站最新草稿。每次提交使用固定幂等标识；网络结果不明时可核对回执或重试同一次提交，不会自动创建新版本。未确认记录只在当前 App 进程与登录期间保留，不承诺重启后的离线恢复；重启后应先检查提交历史。服务端在取得作业锁后重新检查会话、权限、选课、开放窗口和次数。新手机接口强制两项版本校验，旧 API 客户端保留兼容性。

附件通过 Android 系统文件选取器读取单个文件，只在 App 私有缓存内暂存；提交文件沿用网站类型检测、总容量、上传并发和截止规则。下载限定当前作业的教师资料或本人草稿/提交，不开放通用文件接口、其他学生答案或导出包，单文件不超过机构限制及 50 MB。下载后由用户选择其他应用打开/保存，外部副本由所选应用保留；App 私有副本短期清理，退出或身份变化即清理。不会申请整个手机存储读取权限，也不会把 bearer 凭据交给外部应用。

富文本目前原生显示文字与公开 HTTPS 图片；嵌入的私有或相对图片暂显示提示，教师可将相关资料作为作业附件提供，后续随受控课件预览继续迁移。

成绩、总体评语、逐题反馈与评分参考沿用教师发布规则；未发布版本不返回成绩或评语。没有新增数据库迁移，但服务器必须更新 API 镜像才支持 0.2 作业端点。本地账号与服务器账号仍分别存在各自数据库。

设计参考 [Moodle 作业活动](https://docs.moodle.org/en/Assignment_activity)、[Expo 56 DocumentPicker](https://docs.expo.dev/versions/v56.0.0/sdk/document-picker/)、[FileSystem](https://docs.expo.dev/versions/v56.0.0/sdk/filesystem/) 与 [Sharing](https://docs.expo.dev/versions/v56.0.0/sdk/sharing/)。本轮按可独立使用的学生作业流程迁移，并非全站原生迁移已完成。验收结果见[原生作业验证记录](verification/mobile-assignments-20261018.json)。

## 服务器升级

先备份数据库，再按现有部署流程更新网站镜像并执行迁移。新增迁移 `202610170030_mobile_sessions` 向 Session 添加 WEB/MOBILE 类型并创建手机凭据表；旧会话默认 WEB，不重置现有数据。

Nginx 除原 `/api/live/media/` 外，需要加入 [直播代理片段](../deploy/livekit/nginx.location.conf) 中 `/api/live/native-media/` 整段，然后 `nginx -t` 和 reload。保持现有 HTTPS、LiveKit RTC 端口、防火墙和 TURN 配置；不直接公开 LiveKit HTTP 管理接口。

手机平台地址填写 `https://study.huiliyi.cn`，不填 `/api`，不填 API 密钥。App 内使用原有学生或教师账号。服务器未更新手机接口时会提示需要升级。手机使用 HTTPS 证书校验，不允许忽略 TLS 错误。

## 安装依赖和验证

使用 Node 22.22+ 或 24 LTS。原生依赖独立安装，避免与网站的 React 18 混用：

```bash
npm ci
npm ci --prefix apps/mobile
node scripts/verify-mobile.mjs
node --env-file=.data/review.env scripts/verify-iteration.mjs
```

完整验收自动包含原生类型检查、安全回归、依赖审计和 Android Hermes 页面打包，仍包含全部网站测试、真实数据库、三浏览器、迁移空库和四语言可信参考程序。Android 原生二进制与设备验收额外执行下列流程。

### 本地生成安装包

安装 JDK 17、Android SDK platform 36、build-tools 35.0.0 / 36.0.0、NDK 27.1.12297006 和 CMake 3.22.1；设置 JAVA_HOME、ANDROID_HOME。首次构建需要下载 Gradle、Maven 及原生依赖。

```bash
npm run build:preview --prefix apps/mobile
```

输出 `apps/mobile/.data/apk/zhixue-preview-arm64.apk`，可脱离 Metro 安装运行。此包使用公开的 Android 调试签名，仅供内部预览，不用于商店发布。独立包名 `cn.huiliyi.study.preview`，不覆盖未来的正式 App。默认正式 HTTPS 地址，可在登录页更改为信任的平台 HTTPS 地址。

面向本机模拟器的版本：

```bash
npm run build:local --prefix apps/mobile
```

仅此构建允许 localhost、127.0.0.1、模拟器宿主地址 10.0.2.2 的 HTTP，并显示不含凭据的媒体计数；正式预览版本不允许 HTTP。不要将本地测试版作为正式安装包发布。脚本生成的 android/ios 目录不入库，配置通过 app.json 和插件维护。

每次打包会重新生成 JS/Hermes 包；Metro 缓存按平台地址、构建类型和依赖修复指纹隔离。构建脚本额外检查安装包内的平台地址，防止切换本地/HTTPS 版本后误用旧配置，同时检查签名、备份策略、权限、架构及独立运行所需的页面包。

### 独立模拟器完整验收

准备单独的 Android 12+ arm64 模拟器，不使用个人设备；禁用宿主真实麦克风，摄像头使用模拟源。构建网站和 API，准备回环测试数据库及固定版本的本地 LiveKit 测试工具后：

```bash
export MOBILE_TEST_SERIAL=emulator-5580
export DOTENV_CONFIG_PATH=.data/review.env
# JAVA_HOME 指向 JDK 17；ANDROID_HOME 指向含 Android 36 和 build-tools 36.0.0 的 SDK。
node --env-file=.data/review.env --import tsx scripts/verify-mobile-device.ts
```

此流程只清空 `cn.huiliyi.study.preview` 的测试数据，不清理其他应用；通过独立随机数据库、API 和媒体服务验证安装、原生登录、课程进度、重启恢复、双向真实 RTP、教师审批、收回权限、后台退出和注销重登。测试结束删除自身数据库、进程和 adb reverse；结果在 `.data/mobile-device-verification/`。测试不访问真实 AI 或收费判题服务。

设备验收会从 `tests/android/HierarchyDump.java` 编译界面探针，默认只读取实际 Android 无障碍节点；查找长页面控件时可对真实滚动容器发送前后滚动事件，避免触摸越界误触下拉刷新、清除待检查的冲突提示。点击前核对节点位置已稳定。它避免系统默认转储命令等待持续动画而超时，不模拟页面、点击结果或服务器响应，也不进入 App 安装包。每次读取先删除上次转储，防止把陈旧页面当成当前结果；测试结束清理探针及转储。验收记录保存探针摘要。课程视频、资料、暂停续播和跨设备进度冲突也纳入此流程。

模拟源不能证明真实手机的声学回声抑制、蓝牙适配、弱网/TURN、厂商后台限制或实际摄像头效果。上线前仍应使用两台真机/电脑配耳机，分别验证 Wi-Fi、蜂窝网络、拒绝和重新授权设备、教师撤权、断网重连及后台回收。

### 云构建与正式发布

`apps/mobile/eas.json` 提供 Expo EAS 的内部预览和 production 配置。需要项目持有者自行关联 Expo 项目并管理正式签名；本轮没有上传源代码、创建云账号或读取生产签名。正式商店版本还需隐私政策、摄像头/麦克风用途说明、应用备案、发布账号及持久化保存的私有签名密钥。

## 会话与媒体安全

手机 access token 15 分钟，refresh token 单次轮换，总会话期限仍受机构登录策略约束，刷新不延长总期限。每设备最多保留 512 次已消费刷新记录，足够覆盖 72 小时的正常续期；异常高速轮换达到上限后撤销该设备会话，记录随之外键级联删除。数据库仅存摘要；Android SecureStore 通过设备密钥保护会话。系统授权窗口与真正的后台切换分别处理；请求设备权限前暂停已有采集，只有返回前台、课堂仍连接且仍有连麦权限时才恢复。并发刷新由客户端合并；重放已消耗刷新凭据会撤销整个手机会话。网页 cookie 和 CSRF 逻辑继续使用，不通过放宽浏览器 CORS 来接入手机。

原生访问限定在课程读取、进度更新、课堂、学习计划、精确的学生作业与私有附件路径及手机会话接口；管理和其他敏感接口不接受手机 token。媒体 ticket 绑定手机 Session、课堂成员及连接代次。加入、审批和持续连接均复核权限；网页和原生媒体代理不能混用凭据。注销、停用、选课撤销、移出和结束课堂仍由服务端生效。

## 原生依赖审计记录

目前 Expo/React Native 构建链引用的 braces 3.0.3 与 node-forge 1.4.0 尚无包含相应修复的 npm 发布版。不能把原生 `npm audit` 结果表述为零漏洞。原始结果完整保存在 `apps/mobile/.data/dependency-audit.json`，其中多条上层包记录由同一根依赖传递而来。

本项目在安装时对固定版本应用可复核的修复：braces 深层模式/AST 增加深度上限；node-forge 按上游 PR 1152 补上嵌套 DigestAlgorithm 长度校验。每个文件验证安装前后 SHA-256，版本或文件不符立即失败；配有恶意输入回归以及 Node/OpenSSL 独立签名对照。原始包版本不会伪造，公告不会从审计输出中移除。仅在修复文件全部匹配且没有其他未处理公告时，此验收项才通过。decode-uri-component 已升级至公告修复版 0.5.0，并为 query-string 7.1.3 增加带文件指纹的 CommonJS/ESM 兼容修复，课程参数跳转单独回归；UUID 使用 11.1.1。后续应跟进上游正式版本并移除本地修复。

上游依据：[braces 公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)、[forge 修复](https://github.com/digitalbazaar/forge/pull/1152)、[decode-uri-component 公告](https://github.com/advisories/GHSA-vcc3-ghjq-m6fr)、[Expo 56 文档](https://docs.expo.dev/versions/v56.0.0/)、[LiveKit React Native](https://docs.livekit.io/transport/sdk-platforms/react-native/)。

## 原生学生考试（0.4.0 / versionCode 4）

进入“我的考试”或课程考试，可查看考试安排、个人延时及已用次数，开始/继续作答，标记题目、自动保存、确认交卷和查看已发布成绩、答案、解析与评语。禁止回看的考试前进前需要确认。切到后台计时不会暂停；返回时重新核对服务端状态，已到时显示服务器交卷回执。

跨设备更新和保存失败都会暂停写入，确认重新加载后再继续。重启只恢复服务器已同步答案，不支持离线考试；交卷响应丢失时先核对回执或重试本次交卷，不能把本地点击视为提交成功。教师出卷、批改、发布及学生申诉和分析仍在网页。本轮接口需同步部署到服务器。[迁移清单与验收记录](mobile-migration.md)包含完整范围与限制。

## 学生成绩复核（0.5.0 / versionCode 5）

学生从首页“成绩复核”或已交卷答卷进入，提交本人正式成绩的复核申请，并查看受理进度、教师处理意见与改分记录。申请支持确认与未提交离开保护；首份理由不可覆盖，未知提交结果先查回执。每份答卷只生成一份申请，响应丢失后的重试不会创建新申请。

教师在网站处理，敏感改分授权仍需管理员授予，手机不开放教师处理接口。服务端在排队取得锁后再检查最新权限、选课、参考资格、截止及发布状态。成绩撤回时隐藏分数、处理意见和变更明细；网站列表同步修复。未设置截止表示无固定截止，网页与手机使用一致规则。未提交理由不持久保存，重启后需重新填写；已受理记录保存在服务器。

学生首页“学习通知”支持未读计数、类型与分页筛选、单条和本页显式已读，并进入已有原生课程、作业、考试或成绩复核。网站与 App 共用通知记录；原生只展示安全摘要，详情与成绩在当前授权的目标页面重新读取。打开通知不会自动标记已读。

本页确认仅处理当时看到的通知，后来收到的新提醒继续未读。重复标记保持原已读时间；未支持的通知详情请在网站查看。本轮没有系统推送、后台常驻、离线缓存、私信或公告正文迁移，没有新增通知权限。需服务器更新本轮手机接口；本地账号与线上账号不同步。

## 0.7.0 私人学习笔记

学生在首页“学习笔记”查看本人的课时记录，也可在课程中筛选或从选中课时创建。原生支持搜索、置顶、分页、编辑与确认删除，与网页使用同一笔记ID和版本。冲突保留输入，网络结果不明时先只读核对，未保存草稿不会持久保留。服务器需更新新增手机接口，无需数据库迁移。范围与限制见[迁移清单](mobile-migration.md)，实际验证见[验收记录](verification/mobile-notes-20261019.json)。

## 0.8.0 自主练习

首页与课程内提供原生自主练习入口，支持六类题型、逐题确认提交与反馈、复习标记、进度恢复、最近记录筛选和报告。未提交题目不返回参考，首份答案不可修改；网络失败和进度冲突需要明确读取服务器记录。手机创建重试使用固定标识，防止重复生成练习。本轮需应用 `202610190031_mobile_practice` 迁移；独立错题/收藏管理与AI学习尚未迁移。详情见[迁移清单](mobile-migration.md)与[验收记录](verification/mobile-practice-20261019.json)。

## 0.9.0 错题本与收藏管理

学生从首页或课程进入原生错题与收藏页面，按掌握状态筛选错题，分页查看个人记录，确认修改掌握状态、收藏或取消收藏，并进入课程自主练习配置。网站与手机共用记录；跨端变化、新作答和响应丢失后先刷新核对，不能用旧页面覆盖新状态。停止开放的题目隐藏正文，列表不返回参考答案与解析。

服务器需更新新增手机接口，无新增数据库迁移。本轮同步更新Expo 56兼容补丁，原生构建安全回补继续校验。离线复习、AI学习及其他尚未迁移模块见[迁移清单](mobile-migration.md)，测试范围见[验收记录](verification/mobile-collections-20261022.json)。

## 0.10.0 教学公告
