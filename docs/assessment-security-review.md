# 评测安全复查（2026-10-08）

本轮以独立审查数据库和 `http://127.0.0.1:3002` 服务复现，不使用演示数据库。检查范围包括考试生命周期并发、不可回退策略、取消考试后的答案保密、作业附件归属与发布校验；另复查了角色/课程范围、固定题目版本及复核改分的事务条件。

## 已确认并修复的问题

| 问题                                 | 修复前实际证据                                                                      | 修复                                                               |
| ------------------------------------ | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 取消考试与开考竞态                   | 将新答卷暂停在外键插入点，取消考试完成后，新答卷仍成为 `in_progress`                | 开考、取消、资格调整使用同一考试生命周期事务锁                     |
| 撤销资格与开考竞态                   | 同样的真实数据库锁边界下，资格已撤销仍创建有效答卷                                  | 撤销资格与创建答卷串行化，取消已开始答卷                           |
| 预报下一版本号绕过不可回退           | 旧位置检查后，其他请求推进题目和版本；预报新版本的请求返回 200 并将位置回退         | 在答卷行锁内读取当前位置、资格和考试状态，再验证保存策略           |
| 取消历史考试后题目可重新用于保密考试 | 学生已能读取旧答卷标准答案，取消旧考试后同题仍被新考试发布接口接受（201）           | 已有历史答卷的考试题，即使考试取消，也不能重新作为其他考试的保密题 |
| 作业可绑定另一课程的文件             | 当前教师拥有的课程 B 文件被课程 A 作业创建接口接受（201），归属和后续下载授权不一致 | 作业新增、附件编辑及发布均校验预期课程，允许同课程或个人未绑定资源 |
| 作业草稿发布未重新验证题目有效性     | 题目被停用后，已有草稿仍可成功发布（201）                                           | 发布前重新验证固定版本的当前可用性，并在题目锁内重查停用与共享授权 |

考试成绩发布和延时也在生命周期锁内重新读取取消/发布状态；重复成绩发布保持原发布时间。
