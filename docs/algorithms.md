# 学生算法练习

学生登录后从侧栏“算法练习”进入 `/algorithms`。当前提供 18 道原创题、4 条分章节学习路线，以及从审题到复习的完整练习流程。信息组织参考 [LeetCode Study Plan](https://leetcode.com/studyplan/) 与 [Explore 的章节学习方式](https://support.leetcode.com/hc/en-us/articles/360013578114-How-to-use-Explore)；题面、教学内容与参考程序由本项目独立编写。

## 题库与学习路线

题库支持关键词、难度、知识点、作答状态、收藏和复习状态筛选，分页展示。已解决数量来自当前学生正式提交的通过记录；运行样例、自定义运行、查看答案或标为“已掌握”都不会增加通过数。

| 路线                 | 章节                         | 题目                                                                             |
| -------------------- | ---------------------------- | -------------------------------------------------------------------------------- |
| 零基础编程起步       | 熟悉判题流程；数组与字符串   | 两数相加、寻找最高分、回文单词、配对目标值、静态区间求和                         |
| 数组与字符串常用技巧 | 查询与匹配；连续区间         | 第一次出现的位置、括号检查器、最佳连续区间、最长无重复片段、合并重叠预约区间     |
| 动态规划与分治进阶   | 动态规划；分治与合并         | 穿越方格、最少兑换次数、逆序对计数                                               |
| 树与图专题           | 遍历与连通性；依赖与带权路径 | 二叉树的最大深度、网格中的岛屿数量、统计连通分量、学习任务排期、非负权图的最短路 |

每日一题按北京时间日期稳定轮换。推荐顺序为待复习题、曾尝试但未通过的题、学习计划中的下一题。28 天活动图显示真实正式提交次数和当天通过的不同题目数。连续天数按正式提交活跃日计算，可以从今天或昨天连续向前计数；不会被 28 天展示窗口截断。建议天数是学习安排，不是完成承诺。

## 做一道题

1. **审题**：阅读题面、输入输出格式、约束与公开样例；题解页附先修知识和可勾选的审题清单。
2. **独立思考**：渐进提示每次只展开一条，完整题解与答案需要主动展开。
3. **编码**：支持 C++、Python 3、JavaScript、Java。使用完整标准输入输出程序，Java 主类为 `Main`。本地 Monaco 提供高亮、括号/缩进、查找替换、字号、主题、自动换行与全屏；左右分栏可拖动，也可键盘调整。Ctrl/⌘ + Enter 运行、加 Shift 提交、Ctrl/⌘ + S 保存。手机默认简易编辑器，桌面可以切换；Monaco 和 Worker 由本站提供，不依赖 CDN。
4. **自测**：“运行”检查公开样例，也可输入自定义 stdin 和可选预期输出。自定义预期答案只在浏览器本地比较，不改变服务端判题状态；没有填写预期时，运行成功仅表示程序正常退出。公开用例展示逐行输出差异。
5. **提交**：“提交判题”执行公开与隐藏用例。只有正式提交全部通过才更新为已解决。显示答案错误、编译错误、运行错误、时间/内存超限或服务异常。隐藏用例仅返回状态和资源指标。若正式提交发生编译错误，可运行公开样例查看诊断。
6. **学习题解**：逐题提供解法比较、适用条件、实现步骤、正确性说明、时间与空间复杂度依据、样例状态推演、边界用例、常见错误及修正、进阶问题和关联练习。18 题均有四语言完整参考程序。载入参考代码必须确认；载入前自动备份当前草稿，可恢复。简单入门题不人为编造复杂解法。
7. **AI 辅导**：提供提示、详细解析和调试。解析模式结合已编写教学资料，引导模型解释约束、优化、状态变化、正确性与复杂度；调试可关联相同语言和源码的一次运行。提示模式不传完整题解或参考代码，并强制清空模型返回的代码。报告和失败状态均保存。AI 结论与正式判题结果分开，静态诊断不会伪称已运行通过。
8. **复盘**：收藏题目，保存自己的笔记，标记需要复习或已经掌握，再进入上一题、下一题或关联题。笔记只有本人可读；多窗口版本冲突保留输入并展示服务器版本，由学生决定采用哪一份。

草稿自动保存在本机并同步账号；本机尚未同步的更新不会被较晚返回的旧云端响应覆盖。提交历史可查看源码与结果，并恢复旧代码。笔记编辑会先保留本机副本，点击“保存笔记与状态”同步，最多 12000 字符/36000 UTF-8 字节。

## 对比历史代码与当前草稿

在“提交记录”选定一次历史运行或正式提交，展开执行结果中的源码，点击“与当前代码对比”。左侧是选定历史版本，右侧是打开时的当前草稿快照，包含尚未同步的编辑内容。两侧显示语言与来源，历史侧还显示时间、运行类型和结果；文本一致不表示程序正确或正式评测通过。

两侧均只读。桌面可以并排检查，手机使用内联差异；上一处／下一处差异帮助定位修改，完整文本视图保留原源码。比较保留空白差异，Python 缩进和制表符不会被默认忽略。语言不同仍可比较文本，但页面会明确提示，不自动切换主编辑器语言。计算未完成、超时或失败不会显示为代码相同。

“完全相同”只在打开时的两份原始字符串精确相等时显示。不同换行符可能在编辑器中呈现为相同的行，此时仍提示原始文本不同，不用空的行差异结果推断相同。

打开、浏览和关闭对比不会替换草稿、执行代码或调用 AI，也不额外保存比较内容。恢复历史版本必须主动确认，沿用现有编辑与草稿同步流程。对比采用独立模型，关闭、切题或换账号时释放，主编辑器内容及撤销记录继续保留。当前草稿超过现有 16000 字符／48000 UTF-8 字节上限时先提示缩短代码，空草稿可以比较。

此功能使用已有私有提交接口，无需新表或额外服务配置。本人另题的记录仍属于本人；当前工作台只将本题记录加入对比。他人或其他学习空间的记录遵守原有访问隔离。

## 接入与升级

先执行 `npm ci`、`npm run db:generate`、`npm run db:migrate`，再构建或启动服务。迁移 `202610080009_algorithms` 创建草稿、提交、解析和操作记录；`202610080014_algorithm_learning` 创建收藏/复习/笔记状态表。升级应按仓库全部迁移顺序执行，不手工跳过中间迁移。

代码执行通过独立 Judge0 CE 服务，配置方式见 [判题服务](algorithm-judge.md)。应用主机不执行学生代码。生产环境要求 HTTPS；Docker Compose 已透传判题环境变量。未配置时可以查看题目、学习题解、保存草稿和笔记；运行与提交显示未启用。

AI 使用项目现有 `config.yaml` 的 `ai` 配置，默认接入 DeepSeek，沿用可配置模型与结构化输出验证。请求只发送题目公开信息、按模式选择的教学资料、学生主动分析的源码，以及脱敏运行结果；不发送身份、机构、个人笔记或隐藏用例。部署者需填写实际密钥；未配置时界面展示原因。静态详细题解不依赖 AI 配置，随时可学。

题库和学习内容位于服务端 `apps/api/src/algorithms/algorithms.catalog*.ts`、`algorithms.editorials*.ts`、`algorithms.learning.ts`。新增题目必须带稳定 ID、四语言模板、公开样例、隐藏边界用例、详细题解和可信参考程序；同时加入学习路线与独立答案校验。输入输出规则不兼容变化应使用新 ID，避免沿用旧通过状态。当前覆盖完整个人练习流程；题库规模为18题，尚未包含教师在线算法题编辑、竞赛排名、讨论社区和交互式判题。

## 权限、配额与恢复

- 所有接口仅允许学生，要求 `learning.use` 并遵守机构 `practice` 开关。
- 草稿、提交、解析、学习状态始终按机构和当前用户隔离；切换URL不能读取别人内容。
- 学习状态通过 `revision` 乐观锁更新。初始版本为0，首次保存变为1，后续保存递增；过期版本返回409。PATCH省略的字段保持不变，显式空笔记、false和none可清除相应值。
- 每人每天最多200次运行/提交，每分钟10次，同时最多一个判题请求。
- 算法AI每日额度来自 `config.yaml` 的 `limits.dailyRequests`，每分钟最多3次，同时最多一个分析请求；与错题复盘/教师出题额度单独计数，失败也计数，按北京时间计算日期。
- 执行和分析通过事务、锁和租约管理。进程重启或外部超时后，过期处理中记录在下次读取时变为失败；迟到结果不能将已恢复记录改成通过，也不自动重试收费服务。
- 源码最多16000字符/48000字节；学生自定义输入最多16000字符/32000字节。可信题库用例、远端输出、耗时和并发另有边界，见判题文档。

## HTTP 接口

以下路径以 `/api/algorithms` 为前缀，使用现有会话Cookie；写请求要求CSRF Token。完整参数见运行中 Swagger `/api/docs`。

| 方法与路径                       | 用途                                                        |
| -------------------------------- | ----------------------------------------------------------- |
| `GET /status`                    | 判题与AI配置状态、语言列表                                  |
| `GET /overview`                  | 每日题、推荐、活动、统计、计划及章节题目进度                |
| `GET /problems`                  | 筛选分页题库和本人统计                                      |
| `GET /problems/:id`              | 公开题面、模板、本人草稿、学习状态、前后题导航              |
| `GET /problems/:id/editorial`    | 详细教学内容、四语言参考程序和关联题摘要                    |
| `GET /problems/:id/learning`     | 本人收藏、复习状态、笔记、revision                          |
| `PATCH /problems/:id/learning`   | `{revision, favorite?, reviewStatus?, note?}`               |
| `PUT /problems/:id/draft`        | 保存 `{language, code}`                                     |
| `POST /problems/:id/submissions` | `{language, code, mode: run/submit, stdin?}`                |
| `GET /problems/:id/submissions`  | 本题个人提交分页                                            |
| `GET /submissions/:id`           | 本人某次提交结果与源码                                      |
| `POST /problems/:id/analysis`    | `{language, code, mode: hint/explain/debug, submissionId?}` |
| `GET /problems/:id/analyses`     | 本题最近30条本人AI解析                                      |

筛选支持 `q`、`difficulty=easy/medium/hard`、`tag`、`status=todo/attempted/solved`、`favorite=true/false`、`review=review/mastered`、`page`、`pageSize`。题解虽可按需获取，但永远不包含隐藏测试输入/答案。正式提交不接受自定义stdin。AI失败以持久化 `status: failed` 返回，不能仅凭HTTP成功认为生成成功。运行耗时为单个用例最大值，内存为单个用例峰值，不是整批墙钟时间。
