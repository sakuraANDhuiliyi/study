## 性能与恢复

本机：Apple M1、8核、16GB、macOS arm64、Node v22.17.0、本地 PostgreSQL。已执行认证的 `GET /api/courses` 100 请求、并发10：0错误，p50 21ms、p95 33ms、最大51ms、总耗时227ms。此为开发数据和本机条件下的观测，不宣称千人同时考试或生产容量。

已实际停止 API 与后台写入，使用 PostgreSQL 18.1 的 `pg_dump` / `pg_restore` 完成备份并恢复到新建的独立数据库。核对用户23、课程16、作业提交15、考试答卷24、消息14、附件16条记录，所有计数一致；16 个附件逐个 SHA-256 校验通过，备份包校验和通过。验证数据库由脚本清理，原数据库和备份保留。校验结果见 [恢复记录](verification/restore.json)。本机客户端从 PostgreSQL 官方18.1源码构建；embedded-postgres 不包含这两个工具，其他环境需另行安装兼容客户端。真实部署应先停写并演练。

## 已知边界与部署前事项

- Dockerfile、Compose、Linux CI 与反向代理示例已交付并静态审查，本机没有 Docker 引擎，未实际运行容器构建、HTTPS域名发布或 Linux CI。生产上线前仍需在目标环境执行。
- 图文题干保存安全 HTML 和外部 HTTPS 图片 URL，未冻结外部图片二进制；课时支持本地私有图片。编辑器是格式按钮、源码编辑与安全预览，不是完整所见即所得编辑器。
- 综合题支持多个子题与总分一致性校验，人工批阅保存整体得分；尚无逐子题独立批注。作业支持按规则重交，没有学生主动撤回已提交版本的独立按钮。
- 用户导入使用 CSV 解析与整批校验；题库导入使用 JSON，不含 XLSX 适配。规则抽题是基础筛选，不含分层配额。
- 讨论和消息为纯文本加图片/附件；私信管理员默认不可读取，举报治理不会绕过私密范围。
- 视频支持受控访问与学习位置；尚无 Range 分段流、转码或 CDN。上传校验类型、魔数、大小与权限，未配置病毒扫描/CDR。
- 登录限流为单进程内存实现；一层可信反向代理须按 README 配置真实来源IP。生产应结合网关限流；多实例及生产规模压力测试未执行。
- 统计为实时查询，面向单机构常规教学规模；测试没有给出大规模历史数据下的容量承诺。
- S3 存储通过统一接口预留，当前真实实现为本地私有文件；没有配置邮件、短信或外部推送，不能视为已投递。
- 演示账号和演示密码仅用于开发；生产用受控 bootstrap 创建管理员。AI、直播、付费、小程序与摄像头监考属于可选扩展，未启用。
