# 编程创意广场

学生进入编程工作室，点击“创意广场”，或直接打开 `/programming/creative`。当前收录 **41 件作品、41 个 GitHub 来源仓库**，包含空间交互、图形动画、Canvas、绘图、文字、设计工具和数据可视化等浏览器 UI 实验。

当前包含第一批 20 件基础交互、第二批 20 件完整场景，以及 Aora 动态表情实验室。后两类共 21 件列在“本次新增”中，也可以切换“第一批作品”。地球航线、液态玻璃、节点编排、多轨剪辑、编曲、城市沙盘等均提供真实控件和本地状态。

完整来源、固定提交、迁入文件、修改范围、许可及视频对应证据见 [第一批来源清单](creative-sources.md) 和 [本次新增来源清单](creative-wave2-sources.md)。作品不是原项目的完整产品；每件仅保留或重新实现说明中列出的界面与交互。

## 从发现到修改

1. 按分类或关键词查找作品，也可以切换“我的收藏”。收藏只属于当前空间的本人。
2. 打开详情，查看学习目标、来源仓库、固定版本、提取范围与多文件源码。关联视频会标注已核对的仓库；外部包装项目教程与仅提及项目名称的展示标为视觉参考，不混同实际代码来源。
3. 点击“运行预览”体验交互。此操作只创建短期预览快照，不会自动占用项目数量。
4. 点击“创建为我的项目”，为项目命名。服务端使用自己保存的正式作品源码创建私有工作区与第一个版本，随后可以编辑、保存、使用 AI 或下载 ZIP。

列表只传递作品摘要，不发送完整源码或完整许可；打开详情后才加载这些内容。预览和创建请求必须携带详情中作品的源码版本指纹（`revision`）。该指纹由来源信息与完整源码计算；若作品更新，旧请求会被拒绝，需要重新打开详情审阅。浏览器不能传入任意 GitHub 地址或自带源码来替换正式作品。

收藏和新项目按当前机构 / 个人空间与用户同时隔离。同机构其他用户、其他机构用户，以及本人切换后的另一个空间都不能读取旧空间的私有项目或收藏。作品目录本身是所有具备编程学习权限的学生可查看的公共素材库。

## 来源与归属如何保留

每件作品包含 `index.html`、`style.css`、`app.js`、`README.md` 和 `NOTICE.txt`，部分作品还包含本地引擎与许可文件。详情提供上游固定 GitHub 提交及具体文件链接，README 解释中文学习目标和迁入范围，NOTICE 保存完整原作者版权与许可。原有 40 件为 38 个 MIT 来源与 2 个 ISC 来源；Aora 采用限制非商业使用的社区许可，不能将其称为 MIT，也不能据此推断上游未来版本仍使用相同许可。

创建为项目、保存版本、恢复以及下载 ZIP 均携带 NOTICE。创意项目可以改动界面源码，但不能通过保存草稿删除、改名或修改 `NOTICE.txt`。保护归属校验失败时，源码与项目版本号均保持原状。

AI 使用现有 DeepSeek 配置。生成时只发送可编辑的 UI 文件，不发送 NOTICE 的完整许可文本；服务端在返回候选文件前逐字补回原 NOTICE，并忽略模型生成的同名许可文件。生成的源码仍需要审阅后确认应用，应用前保存已有源码快照。即使应用已准备好的候选，服务端也会再次校验来源文件。

## Aora 动态表情实验室

作品 `aora-expression-lab` 来自 [sam70361/aora-bot](https://github.com/sam70361/aora-bot/tree/e3b6148c818da4a8e1966f2bc89cdb3cee473b73)，固定提交为 `e3b6148c818da4a8e1966f2bc89cdb3cee473b73`。完整迁入 `emotion-ball/js/rings.js`、`emotions.js`、`ball.js` 和 `engine.js` 的已审查原文，保留 32 种 SVG 表情（8 种生命周期、12 种情绪、12 种代理状态）和 blob / wedge / gem 三种身体形态。宿主界面由本项目编写，提供分组与搜索、逐项切换、线稿、播放与暂停、自动巡演，以及本地模拟的工作状态消息。消息示例不调用 AI，也不接入上游服务。

只有一个主 SVG 实例参与动画；切换身体形态先销毁旧实例。系统减少动态效果时展示静态帧并禁用巡演；暂停、页面隐藏和偏好改变均停止巡演定时器与动画，离开预览时销毁实例。全部引擎文件由隔离预览本地提供，不加载外部字体、图片或脚本。

按固定版本的 [LICENSE](https://github.com/sam70361/aora-bot/blob/e3b6148c818da4a8e1966f2bc89cdb3cee473b73/LICENSE) 与 [NOTICE.md](https://github.com/sam70361/aora-bot/blob/e3b6148c818da4a8e1966f2bc89cdb3cee473b73/NOTICE.md)，球形角色视觉形象仅供个人技术学习、研究及非商业技术交流，禁止任何商业用途，且不提供商业授权；引擎与表情数据的商业使用须另行获得授权并搭配合法角色形象。详情和预览均显示使用范围。源码包保留原 `NOTICE.md`、`LICENSE.txt`、`LICENSE-COMMERCIAL.md`，并将完整许可和使用声明聚合到受保护的 `NOTICE.txt`，随项目复制、JSON 备份与导入继续保留。

可运行 `node --import tsx scripts/verify-aora-expressions.mjs` 验证实际 sandbox 中的 32 种表情、筛选、形态、播放、减少动态效果与手机布局；`node --import tsx scripts/creative-covers.mjs --only=aora-expression-lab` 只更新本作品封面，保留其余封面。

表情实验室的 AI 改写仅处理 `index.html`、`style.css`、`app.js`、`README.md` 与自行新增的可编辑文件；服务端不向模型发送其四个已知 vendor 引擎文件或独立许可文件，并在候选结果中逐字补回当前项目中的这些文件，忽略模型对相同路径的覆盖。这样无需让模型重新生成完整引擎，也不会超过已有返回长度上限。学生在源码编辑器中手动修改过的引擎同样保留。完整候选合并后仍检查 24 文件和 256 KiB 上限。

2026-10-09 验证通过：全项目 416 项单元测试、创意与编程共 35 项 HTTP/数据库测试、实际 sandbox 的十组浏览器检查，以及本地服务的详情、预览与 390px 页面检查。类型、ESLint 和构建通过；AI 使用本地协议夹具，不代表真实远端生成质量已验证。完整来源哈希和记录见 [表情接入验证](verification/aora-expressions.json)。

## 本地预览与容量

预览与主应用使用不同主机名和独立服务，由 `sandbox="allow-scripts"` 的 iframe 显示，不授予同源父窗口权限。默认本地预览来源为 `http://127.0.0.1:4173`，应用为 `http://localhost:5173`；具体配置见 [编程工作区说明](programming.md)。

每个预览约 **10 分钟**后过期，失效后重新运行即可。每个账号同一空间最多保留 3 个当前预览快照，每分钟最多创建 20 次；预览不设置登录 Cookie。访问预览资源时仍校验其拥有者的会话、学生权限、当前空间与机构功能开关。退出、撤销角色或关闭练习功能后，原链接无法继续访问。

作品与个人项目共用文件读取保护：默认每用户每分钟 480 次、每链接 240 次、每直连 IP 9600 次，GET/HEAD 合并计数。同一用户跨链接最多 24 个读取验证并发，全局最多 32 个，因此完整 24 文件页面可同时加载，其他用户也保留可用槽位。用户配额或并发超限返回 429，全局容量不足返回 503，均附 Retry-After；限流状态有容量上限并清理过期窗口。服务只使用 socket IP，忽略客户端代理头；调整参数及其有效范围见[编程工作区说明](programming.md)。

预览限制外部资源与网络请求，所收录的演示数据、图形及状态在浏览器内生成。iframe 提供浏览器内容隔离，不是服务器进程或 CPU 配额沙箱；编写无限循环仍可能影响浏览器。此模块不会在主机执行项目代码、终端命令或 npm 安装脚本。

创建后的工作区沿用现有上限：每个用户当前空间最多 20 个项目，每个项目最多 24 个文件、单文件 64 KiB、源码总量 256 KiB，最多 30 个保留版本和 20 个 AI 候选。AI 生成使用已有每日共享额度，模型返回失败也计入已发起操作。

## 当前范围

迁入内容仅为 HTML / CSS / JavaScript 的界面、图形与交互。来源仓库的 Android、React Native、Python / Node 后端、账号登录、数据库、支付、云服务或其他业务逻辑没有接入。改写过的小函数、独立实现的界面模式以及简化实验在来源文档中逐项说明。

分轨编曲台仅在用户点击后启用浏览器合成音，停止或离开页面即结束；所有图形、样本和城市数据均为本地演示数据。

当前提供本地预览和源码 ZIP，没有远程网站发布、子域名配置或上游仓库自动同步。后续接入部署平台时，需要另行配置域名、部署环境和发布权限；现有预览地址不代表已部署的公开网站。
