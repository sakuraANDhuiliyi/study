## 迁移顺序与依据

[Moodle 官方 App 能力](https://docs.moodle.org/en/Moodle_app_features)将课程、待办、活动完成、成绩、交流与日历作为移动学习的主要路径。结合本项目已有后端，实施顺序为学习计划 → 作业与成绩反馈 → 视频及附件 → 考试与通知 → 练习/算法/编程/专业学习 → 教师与管理功能。该顺序是本项目的实施判断，不表示表中的未完成项已开发。

视频使用 [Expo 56 对应的 expo-video 文档](https://docs.expo.dev/versions/v56.0.0/sdk/video/)评估；文件使用 [Expo 56 FileSystem 文档](https://docs.expo.dev/versions/v56.0.0/sdk/filesystem/)评估。新增依赖须匹配现有 SDK，不能为了显示网页而把后台 bearer 凭据传给不受控浏览器或第三方。

## 一致性要求

- 逐条扩展原生接口许可，继续复用业务权限与数据库事务；网页 Cookie/CSRF 与原生 bearer 不混用。
- 选课撤销、账号停用、机构开关、成绩发布、考试截止和文件授权由服务端重新确认。
- 草稿冲突显式处理；网络断开后先查询确认提交结果，不能无条件重复创建或交卷。
- 真机、蓝牙、校园网/蜂窝网络与 TURN 验收独立于模拟器测试；合成摄像头的成功不能替代硬件验收。
- 本地测试与 HTTPS 预览连接不同数据库，本地演示账号不会自动同步至服务器。

## 0.3.0 课程资源与续播范围

学生可加载已开放课时的私有 MP4 视频，使用原生播放器播放、暂停、前后跳转，恢复服务器记录的位置。每15秒及暂停、进入后台、离开播放器时尝试保存进度。进入后台暂停，不自动恢复声音；视频播放不会自动标记课程完成，完成仍由学生主动确认。

下载接口只接受当前课时直接引用、同机构且属于该课程的文件，不能读取私信、作业、导出记录或任意文件。单次资源上限50 MiB，下载后校验长度再写入 App 私有缓存。视频离开课时清理，资料交给系统工具时短暂保留读取窗口，切换身份及退出清理缓存。用户另存至外部工具的副本归外部工具管理。此功能不等同于持久离线课程。

网站与本版 App 使用服务器更新时间作为保存前提，在同一学生、课时事务锁内核对版本、会话、选课及开放时间。跨设备冲突或保存失败时暂停并提示重新加载，以服务器进度为准。旧版客户端保留原有接口兼容性，不具备本版的冲突提示。离开页面时的网络保存是尽力而为；离线时请留在课时查看保存结果，不能承诺恢复未上传的位置。

外部 HTTPS 资源通过系统浏览器打开，不传递 App 登录凭据。大文件、外部视频原生播放、全屏播放和更多格式仍待迁移；教师编辑课件和上传资料继续使用网站。服务器需更新本轮接口，本地账号与线上账号仍独立。

## 本轮：原生学生考试（0.4.0 / versionCode 4）

首页“我的考试”、课程“查看课程考试”、学习计划中的学生考试目标进入独立原生页面。列表支持搜索、课程范围与分页；详情展示开始、结束、允许进入、个人延时、次数和禁止回看规则。开始与继续复用同一服务端答卷，支持六种题型、题目标记、答题导航、自动保存与手动保存。服务器控制题目顺序、个人截止、资格和最终交卷；手机使用服务器时间及单调时钟显示剩余时间。

切到后台尽力保存，回到前台重新核对答卷；计时不暂停。网页或其他设备更新后，手机保留当前显示并暂停写入，需明确舍弃未同步修改、加载服务器答卷。网络失败不会自动重放可能已成功的保存。未同步答案只在当前页面内存中，不能保证断网、进程终止后的恢复；重新进入仅恢复服务器已保存内容。禁止回看的考试只允许下一题，先同步再前进；确认前进后不能返回。

交卷前显示未答数量并再次确认，先同步答案，再发送固定幂等标识。交卷结果不明时冻结编辑，可核对服务器回执或重试同一次交卷。服务器在答卷锁内重新核对当前会话、权限、选课、考试状态和资格，手动、重复、到时交卷只认同一份答卷。成绩、答案、解析与评语分别遵守原有发布规则；本轮不迁移教师阅卷、申诉、成绩分析和考试附件。

本轮无需数据库迁移，线上服务必须更新后才能使用新增的手机考试接口。接口只允许学生 MOBILE 会话，未开放通用考试、阅卷、受众管理或其他学生答卷权限。[完整验收记录](verification/mobile-exams-20261018.json)与[Android 考试截图](screenshots/mobile-android-exam-result.png)记录实际验证范围。

本轮参考 [Moodle 官方考试流程](https://docs.moodle.org/503/en/Using_Quiz)中进入、标记、未答确认、自动保存和按教师设置复核的流程，结合本项目现有 CAS 和服务器计时规则实现；这是本项目的取舍，并不表示实现了 Moodle 的全部能力。前后台与计时依据 [React Native 0.85 AppState](https://reactnative.dev/docs/0.85/appstate)及 [performance](https://reactnative.dev/docs/0.85/global-performance)，导航与随机标识使用 [Expo 56 Router](https://docs.expo.dev/versions/v56.0.0/sdk/router/)和 [Crypto](https://docs.expo.dev/versions/v56.0.0/sdk/crypto/)对应版本。

## 本轮：原生成绩复核（0.5.0 / versionCode 5）

首页“成绩复核”和已结束答卷中的“成绩复核与变更记录”进入原生页面。学生可以核对正式成绩与复核截止，填写理由、二次确认提交，查看申请回执、待处理/已处理列表、教师处理意见和分页成绩变更。教师继续在网站处理；改分仍需要独立的敏感授权，App 没有获得教师处理或改分接口权限。

每份答卷只受理一次申请，首份理由提交后不能修改。重复点击、网页与手机并发、响应丢失后的重试均返回同一申请，不重复审计。服务器已受理的回执可以在截止后查询和恢复。未设置截止沿用服务端原有规则：没有固定截止；网页入口已与该规则一致。新的申请仍必须满足本人当前选课、参考资格、已交卷、正式成绩已公开、考试有效及截止规则。

提交结果不明时保留本次理由并暂停编辑，可先核对服务器回执或重试同一份申请；明确的格式、权限或截止拒绝允许修正或刷新条件。未提交的理由只在当前页面内存中，离开需确认，重启不会恢复。切换身份、会话撤销和选课变更均重新验证，不做离线申请。

申请及教师处理在取得答卷锁后使用同一事务连接重新核对会话、权限、选课、当前指定阅卷人和敏感改分授权。成绩未公开、重新批改或撤回发布时，不显示有效分数、处理意见中的成绩信息及变更明细；网站复核列表也遵守同一公开规则。手机只接收本人的安全字段，不传递教师内部账号或审计操作者标识。

参考 [Canvas 官方成绩历史说明](https://community.instructure.com/en/kb/articles/660864-how-do-i-view-the-history-of-all-grading-changes-in-the-gradebook)中的只读变更记录、修改前后分数及当前有效分数，以及 [Moodle 官方复核显示设置](https://docs.moodle.org/503/en/Quiz_settings)对学生可见内容与公开时间的区分。手机按 [Expo 56 Router 文档](https://docs.expo.dev/versions/v56.0.0/sdk/router/)保留原生导航；具体的复核申请规则沿用并加固本项目服务端，未照搬其他平台的教师查看范围。

无需新增数据库迁移。服务器必须同步更新，才可使用新版手机复核接口。考试分析和教师原生处理尚未迁移。[完整验收记录](verification/mobile-review-20261018.json)及[Android 复核截图](screenshots/mobile-android-review-result.png)记录实际验证结果。

## 本轮：原生学习通知中心（0.6.0 / versionCode 6）

学生首页“学习通知”进入原生通知中心，支持全部/未读、作业/考试/成绩/课程/其他类型、分页、刷新，以及明确的单条或本页标记已读。读取与标记复用网站的本人通知记录，网页和手机的已读状态同步。进入页面不自动已读，打开学习目标也不自动标记；学生可主动区分已查看和仍需处理的事项。

通知只返回受控类型摘要、时间、已读状态和是否有原生入口，不传递历史标题、正文、分数、教师处理意见、事件标识、内部账号或原始链接。支持的提醒经服务器重新核对本人通知、机构、当前会话、选课、课程状态、作业开放与受众、考试资格及答卷归属后，返回有限的原生课程/作业/考试/复核目标。目标页面再次验证当前权限与成绩公开规则。撤权或资源删除后不能借旧通知进入；未知类型、外站地址、路径参数和未迁移功能不自动打开网页，也不传递登录凭据。课程公告提醒可进入课程，但公告正文尚未原生迁移。

“本页未读标记已读”二次确认时固定当前看到的最多20个通知ID，服务器核对整组归属后原子更新。混入别人的记录时整组拒绝，重复操作不改写首个已读时间；确认期间新收到的提醒不被顺带标记。响应丢失后可刷新核对，再安全重试同一组记录。本页操作不等同于全收件箱清空。应用内定时刷新和回到前台刷新，未实现操作系统推送、后台常驻、离线收件箱或持久缓存。

本轮参考 [Moodle 官方通知说明](https://docs.moodle.org/503/en/Notifications)中的未读计数、通知列表、显式已读与进入相关活动的流程；只处理本页快照是本项目为避免误读新提醒作出的取舍。原生导航与生命周期按 [Expo 56 Router](https://docs.expo.dev/versions/v56.0.0/sdk/router/)及 [React Native 0.85 AppState](https://reactnative.dev/docs/0.85/appstate)对应版本实现。没有新增依赖或系统通知权限。

无需数据库迁移；服务器需更新本轮接口。本地与线上账号仍独立，教师通知页面、公告正文、讨论、私信和系统推送仍待迁移。[完整验收记录](verification/mobile-inbox-20261019.json)及[Android 通知截图](screenshots/mobile-android-inbox.png)记录实际验证范围。

本轮设备验收同时补齐返回键的输入保护：键盘可见时先收起键盘并移除输入焦点，不触发页面返回或考试离开确认。键盘关闭后，原有未保存确认与考试计时规则继续生效。按 [React Native 0.85 Keyboard](https://reactnative.dev/docs/0.85/keyboard) 及 [BackHandler](https://reactnative.dev/docs/0.85/backhandler) 对应版本实现，使用真实 Android 输入与考试恢复验证。
