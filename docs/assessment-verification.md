## 明确边界

- 图文题干使用安全 HTML 与外部 HTTPS 图片地址；题目版本固定 HTML 和 URL，尚未实现题目私有图片库及图片二进制版本快照。图片网址失效会影响显示。
- 综合题支持多个子题、子题分数合计校验和整体人工评分；尚未单独保存每个子题的评分与批注。
- 作业支持有次数与时间限制的重新提交；没有学生主动撤回已提交版本的独立操作。
- 题库支持 JSON 模板、整批校验、错误行反馈和导出；尚未提供 Excel 文件导入导出。规则抽题支持基础筛选，不含多知识点分层配额。

这些边界不应在交付说明中被写成已完成的功能。Docker、生产规模并发和浏览器验证不由本记录替代。
