调研及实施日期：2026-10-08。对照本项目现有课程、交流、评测、权限和部署文档，检索并阅读 Moodle、Canvas / Instructure 和 Open edX 的官方产品说明与接口文档。下列优先级是针对本项目的判断，不是原平台的排名。

## 1. 学习日历与个人待办

入口：侧栏 **学习日历**（`/planner`），学生和教师工作台也有快捷按钮。

- 桌面月历、日程列表、按作业/考试/个人待办筛选；手机默认日程列表，也可切回月历。
- 作业与考试从当前授权范围实时汇总；个人待办独立保存，支持标题、说明、时间、完成、重新打开、编辑和删除。
- 时间显示与输入均使用 `Asia/Shanghai`，即使浏览器系统在其他时区也按北京时间提交。
- 作业采用 `max(原截止, 本人批准补交截止)` 在日历定位，同时显示原截止与补交说明。补交不自动变成“按时提交”；最新提交被退回时仍标记待重交。
- 考试按时间区间显示，跨月仍可见；本人已开始的答卷优先显示实际交卷截止，另显示允许进入截止。取消考试标记取消。
- 正式教学安排不能由个人待办按钮修改。个人待办只能修改自己的记录，管理员不获得代读代改权限。
- 使用 `revision` 拒绝旧页面覆盖新修改，冲突时保留输入，可载入最新版本后重新决定保存。

接口：

| 方法   | 地址                                      | 说明                                                       |
| ------ | ----------------------------------------- | ---------------------------------------------------------- |
| GET    | `/api/planner?start=ISO&end=ISO&type=all` | 半开时间范围，最长93天；type还可为assignment/exam/personal |
| POST   | `/api/planner/tasks`                      | `title`、`description`、`dueAt`                            |
| GET    | `/api/planner/tasks/:id`                  | 本人待办详情与最新版本                                     |
| PATCH  | `/api/planner/tasks/:id`                  | 必传revision，可改内容/时间/completed                      |
| DELETE | `/api/planner/tasks/:id`                  | body必传revision                                           |

每类最多返回500项；超量返回 `truncated=true` 并在页面提示缩小范围，不声称返回全量。默认管理员原本没有作业/考试管理权限，日历也不会绕过这个限制。日历响应不包含题干、答案或他人成绩。

## 2. 私人课时笔记

入口：课时页 **我的课时笔记**；侧栏 **我的笔记**（`/notes`）。

- 每位用户每个课时一条笔记，纯文本最多10000字符，支持编辑、置顶、删除、跨课程搜索与分页。
- 从笔记列表可返回对应课时；刷新后内容保留。
- 四种身份都只看自己的笔记。读取、写入和列表查询同时校验所属机构、本人、当前课程授权；学生还受课时开放时间限制。
- 课程撤权或课时不再开放时，不通过旧笔记链接泄露课时信息。教师仍可在自己的课程中记录备课笔记。
- 并发版本冲突明确提示；不会自动覆盖当前输入。未保存即关闭编辑器有确认提示。

接口：`GET /api/notes` 支持 `search/courseId/pinned/page/pageSize`；`GET/PUT/DELETE /api/lessons/:id/note` 读写本人笔记。创建使用 `revision=0`；修改和删除必须同时提供 `noteId` 与 `revision`，防止旧页面覆盖删除后重建的新记录。

## 3. 教师考试题目分析

入口：有阅卷权限教师打开 **考试详情 → 题目分析**。

- 从已发布考试的固定题目快照和真实答卷统计，不会混入题库后来修改的版本。
- 每位学生取最近一次已交卷或超时交卷的答卷；后续正在作答的重考不会遮掉已有交卷。取消的答卷排除，取消考试的报告标明历史统计。
- 展示每题参考人数、作答/空答人数、已批/待批人数、客观完全正确率、平均得分及得分率。
- 单选、多选和判断题展示选项频次。多选同一选项去重，各选项比例之和可以超过100%。不返回学生身份、原始自由文本答案、标准答案或解析。
- 正确率按固定标准答案计算，人工调整的得分单独反映在得分率；部分分不算完全正确。待阅卷不按零分计算，无样本显示无数据。
- 少于5人时标记小样本，不据此自动判定题目质量。不伪造信度、区分度等尚未实现的心理测量指标。
- 延续当前课程授权和指定阅卷人规则。学生拒绝访问；默认管理员没有阅卷权限，仅有敏感统计授权也不足以访问教师报告。

接口：`GET /api/exams/:id/item-analysis?page=1&pageSize=20`，每页最多50题；答案通过1000行游标批次聚合，在一致性事务中读取。

## 数据、维护与验证方式

新增 `PersonalTask`、`LessonNote` 两表及正式迁移004、005；006调整新表的数据库文本护栏，兼容本地旧SQL_ASCII开发库。API仍按字符数限制输入，数据库使用保守字节上限并保留外键、唯一性和版本约束。已有业务表数据不需要重置。

新环境按README执行 `npm run db:generate && npm run db:migrate`；已有环境备份后执行同样的迁移步骤。Swagger补充了新接口与写入参数。

`npm run test:extensions` 执行三组新增数据库/HTTP回归；`npm run test:browser` 自动包含三个新模块的浏览器用例。业务测试使用独立验证库，避免向本地演示数据添加验收记录。
